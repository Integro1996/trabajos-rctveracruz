# Fondo institucional

`plantilla.docx` es una copia de `rctveracruz2026-PRUEBA-GENERADOR-DOCS/assets/img/plantilla.docx`. Se conservan sus imágenes, posiciones, tamaño carta y márgenes originales. No se modifica el archivo fuente.

`src/page-template.js` incorpora sus encabezados y pies al DOCX generado sin sustituir el cuerpo, tablas ni imágenes del autor. El encabezado y pie se repiten en todas las páginas. El título, autores y keywords continúan en PostgreSQL.

Los documentos antiguos adoptan este fondo al pulsar **Generar documento**. Se conserva el cuerpo ya generado o editado en ONLYOFFICE, se recalcula la paginación y se guarda una nueva versión. Las versiones históricas conservan su apariencia original.
